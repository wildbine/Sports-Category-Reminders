# Спортивные разряды

Минимальная основа мобильного приложения для тренера по художественной гимнастике. Сейчас в приложении есть стартовый экран и переключение между разделами списка детей и личной судейской категории.

## Запуск

Нужен Node.js LTS.

```bash
npm install
npm start
```

Откройте проект через Expo Go или запустите эмулятор Android/iOS. Для запуска на устройстве установите Expo Go и отсканируйте QR-код из терминала.

Проверка TypeScript:

```bash
npm run typecheck
```

## Основа проекта

- React Native, Expo и TypeScript
- Обычные компоненты React Native, без дополнительной UI-библиотеки
- Backend, хранение данных, CSV-импорт и уведомления пока не подключены

## Структура

- `App.tsx` — точка входа Expo
- `src/screens/` — экранные композиции и их стили
- `src/components/` — общие компоненты и их стили
- `src/theme/` — общие цвета и визуальные токены
- `app.json` — настройки Expo
- `.github/agents/sports-category-reminders.agent.md` — проектный агент Copilot
